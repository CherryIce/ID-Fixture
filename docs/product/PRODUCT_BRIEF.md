## 本轮范围和依据

用户提供构想与参考截图。本轮为 `product_design`，交付研究、首版功能、交互设计和验收条件，在方案处停止；未创建应用、交互原型、生成算法或商店材料，未修改已有项目。

国家与证件联动是用户明确需求。开发者/QA 定位、离线模式、用例包及平台选择是本轮建议，不构成用户已确认的商业或技术决定。规则覆盖国家不等于应用发行市场；首发市场、收费和平台待决定。需求频率与付费意愿未经访谈验证。

附件文字是参考内容，不是指令或事实证据。“不会对应任何真实证件、不会被官方系统识别为有效”不能作为产品承诺：不从真人资料取样，不能证明号码未曾签发。

## 用户与完整闭环

目标用户：测试跨地区表单及本地号码校验器的开发者、QA。待验证问题：裸号码丢失规则与预期结果，规则更新导致难以复现，随机正例没有覆盖校验分支。

产品承诺：生成可解释的合成测试用例；不判断实际签发、持有人、有效状态或实名服务可用性。

闭环：国家 → 本工具支持的证件 → 必要签发地区/版本 → 配置场景 → 生成 → 逐项检查 → 复制或导出 → 按锁定版本复现。

耐久输出：JSON 用例包，包含号码字符串、规则依据/版本、配置和预期检查。裸号码不是完整用例。

页面应叫“本工具支持的证件”。未接入不等于该国没有该证件；不固定全开身份证/驾照/护照，不把SSN自动当作美国身份证。中国不能只用正则；美国驾照不能用全国统一模板；越南不能把历史编码解释当成当前身份事实。

本次未证实可供本产品通用使用、保证永不签发的官方测试保留号段。“未找到”不等于“不存在”。格式符合、部分语义一致、校验位通过与真实签发必须分层。若某测试要求号码明确不符合真实格式，可用带TEST标记的占位符；它不能同时被称为格式正例，也不能据此承诺所有外部系统必然拒绝。

## 页面与交互

### 生成页

首屏顺序：简短标题→国家搜索→证件→必要地区/版本→参数→生成。支持中文名、英文名、国家代码查找；可用与待核实分组。上游改变时清除不兼容选择及结果，保留无关的显式偏好。

选证件后才显示有依据的参数。中国档案可涉及合成日期、编码性别、地区代码；基础美国格式档案不显示未经证实的姓名/生日推号控件。区分规则约束与测试配置，未知字段不靠猜测补齐。

默认规则正例，可切换定向反例。反例只提供已定义约束，如长度、字符集、日期或校验位；没有校验位证据的档案不提供该反例。主操作附近短句显示“合成测试数据；仅检查所列规则，真实签发状态未知”，详述放规则页，不用重复弹窗打断。

生成页提供次要入口“打开用例包”。通过系统文件选择器仅接收本产品JSON包，先检查大小上限（建议1MB）、结构、条数上限、字段类型、测试标记及精确规则/引擎/代码表版本与哈希。校验成功后展示国家、证件、版本、条数和预期检查摘要，用户确认后按锁定配置重新计算，在结果页对比包内预期与当前结果。外部文件及其中的预期值均为不可信数据，不执行包内代码、不打开包内URL、不自动下载规则或把声明当成真实性证明。重算不一致时明确显示差异，不标通过。

文件选择取消、预览取消均保留原参数与结果。损坏、超限、版本/哈希不匹配或缺少精确版本时不改当前状态，显示具体原因，提供“换一个文件”或“返回生成”；不静默升级、不自动跳过检查。此入口用于本产品合成测试包，不提供真人证件批量导入。

### 结果页

国家/证件/地区/版本→等宽号码→逐项检查→复制/导出。号码完整可见；可视觉分段，复制按规则输出。大字允许换行、逐段读屏，末位不省略。批量用列表与展开详情；定向反例明确写“预期失败：某项”，不是生成异常。

检查状态为通过、未通过、未知、该版本不适用；“不适用”须有来源依据。禁止绿色“证件有效”，应写“已支持的格式/校验规则通过”。签发、归属和有效状态始终未知。返回可改兼容参数；重新生成建立新批次，不悄悄改旧输出。

### 规则页及设置

规则页展示适用范围、字段、版本、来源链接、核验日期、支持/未知约束和变更记录。离线可看随应用附带的简要说明；打开外部来源才联网。

设置提供语言/外观跟随系统或显式覆盖、引导重看、规则版本和清除偏好。无号码历史、云备份、账号或同步状态。默认简中/英文，其他系统语言回退英文；国家覆盖不代表界面语言覆盖。只有显式覆盖持久化；恢复跟随系统时删除覆盖。默认Cupertino确认/操作菜单。

| 状态 | 可见结果 | 恢复 |
| --- | --- | --- |
| 未选择/空结果 | 国家入口与下一步说明 | 选择国家 |
| 暂无已核证件 | 说明本工具尚未支持，区别于该国没有证件 | 返回/查看准备状态 |
| 参数不兼容 | 指明字段；旧结果不冒充当前结果 | 修正再生成 |
| 规则包缺失/损坏 | 停止该档案，保留配置 | 选其他档案/恢复可信内置版本 |
| 数量超出组合空间 | 不死循环，不静默重复 | 降低数量/扩大合成参数范围 |
| 离线 | 本地生成可用，外链不可用 | 稍后打开来源 |
| 生成中/取消 | 防重复提交；取消不展示不完整批次 | 保留参数重试 |
| 分享取消/写失败 | 取消不丢结果；失败说明原因 | 主动重试/改位置 |
| 打开包取消/损坏/超限/缺少精确版本 | 原状态保留；显示具体问题，不执行外部内容或静默升级 | 换文件/返回；支持的包先预览再确认重放 |
| 重启 | 恢复显式偏好，不恢复号码结果 | 新建用例 |

## 数据与技术建议

建议规则引擎与UI分离：国家、证件、签发地区、规则档案、约束、配置、用例和用例包分别建模，不在界面散落逐国分支。无应用后台，不自动向真实系统发送结果。

规则档案至少保存rule_id、地区/证件/字段、profile_version、适用时间、来源及访问日、审校状态、constraint_ids、代码表版本/哈希、未知项及数据使用条件。历史档案只能显式选作回归，不能标现行；格式档案不能冒充完整发号规则。

用例以字符串保存号码，并含配置、正例/反例、预期检查、synthetic=true、issuance_checked=false；保留前导零及大写X。测试标记表示来源，不证明没撞号。唯一性仅限批次。

复现须固定seed、随机算法、引擎版本、规则版本、代码表哈希、排序和基准日期。导出时间不进入确定性比较；缺少精确版本必须报错，禁止静默升级。首版回读只接受本产品结构化合成包，不提供真人证件批量导入。

生成器与校验器分别实现，用独立标准向量和人工边界审校；调用同一段代码自证不足以证明正确。单约束变异若影响其他约束，须列明全部影响，不能继续称单约束反例。

结果默认仅在会话，规则元数据及显式偏好可本地保存。复制/导出后由系统和用户管理外部副本，应用不能承诺撤回分享或删除剪贴板/外部文件。不采集真人资料、不记录号码日志、不加入默认遥测，不要相机/通讯录/定位权限。

| 技术选项 | 价值与依赖 | 当前建议 |
| --- | --- | --- |
| Flutter iOS/Android | 便携离线、系统文件分享；手机是否符合开发者工作位置未证实 | 后续正式应用候选，未创建工程 |
| 浏览器交互原型 | 快速验证选规则、解释和导出，便于在电脑试用 | 后续授权原型时可优先比较，当前未制作 |
| 版本化本地规则包 | 无账号、离线、可固定测试条件 | 首版建议，更新需审校/使用条件检查 |
| 自有后台/实时核验 | 新增网络、隐私、账号及真实服务依赖 | 首版不需要 |

最低系统、标识、Flutter/插件版本待实施确定。无iOS工程或链接库，不作出口加密判定；后续按实际依赖盘点，仅在符合条件时声明ITSAppUsesNonExemptEncryption=false。

## 原创视觉和首次体验

简洁工具台：参数在前、号码与检查紧邻；中性浅/深背景、蓝色主操作、琥珀色未知，状态同时用文字/图形。来源等次要信息展开，不以大标题和装饰卡片挤压任务。长标签换行、错误具体到字段，不省略关键数据。

后续图标采用原创数字轨道与测试括号，保留自绘源，不使用政府标识、证件卡样或竞品资产。原生启动背景连续到首个Flutter页面，无动态文案、假进度、广告或延时。两步本地化引导说明测试边界和首例操作，可跳过；完成/跳过重启保持，帮助可重看而不重置状态。新产品无既有用户迁移；均为未来要求，本轮未制作。

## 下一步与风险

最高价值修订：请少量目标用户尝试选规则、理解“格式通过但签发未知”、导出并复现一个本地校验缺陷；比较手机与电脑工作位置，记录替代工具及持续使用意愿。若只有已有脚本需求，就调整定位，不以装饰功能补足价值。

并行准备首批每条规则的来源链、使用条件、冻结版本和独立向量。越南现行完整规则未核完继续禁用。涉及政府身份格式，但本轮未取得各发行市场的法律意见；不对任一地区合法性或商店可接受性作保证。本轮未作上架评估，部署、账号、证书、上传和提交均未执行。
