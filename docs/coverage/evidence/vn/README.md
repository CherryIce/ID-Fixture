# 越南个人身份编号覆盖研究

核验日：2026-11-05（Asia/Shanghai）。角色：只读规则研究；本目录仅保存来源、机器数据和研究结论，未修改 Dart、JS 或 UI，未构建应用。

## 可实施结论

可以启用“越南个人身份编号 · 12位公开结构”的**格式测试数据合成**。`vn-coverage.json` 提供当前 34 省市导航和 63 个历史公开出生登记地编码，覆盖越南国内全部区域。这里的“当前”修饰省市导航；不等于已经核验 2026 年新签发号码的全部分配规则。

- 当前 34 省市采用 `19/2025/QĐ-TTg` 附录 I 的两位**行政代码**。
- 输出前三位从 `legacyBirthplaces63` 选择，采用已公开的出生登记地编码。当前省市只负责把有关历史编码聚合显示。映射依据 `202/2025/QH15` 第 1 条；它不是政府发布的“身份号码转换表”。
- 不得把当前两位行政代码直接补零当作已经核验的新身份证前缀。例如当前 Bắc Ninh 行政码为 24，但旧 Bắc Ninh 编码是 027；当前省所含的原 Bắc Giang 编码是 024。
- 用户选择一个合并后的省市时，应展示或明确记录具体编码地区，避免只显示当前省名而隐去随机选中的历史地区。导出至少记录 `currentProvinceAdminCode`、`legacyBirthplaceCode`、`ruleVersion` 和 `assurance=format_only`。
- 不连接人口库；不声称已签发、实名相符、不会撞真实号码或可通过 KYC。未发现可供公众使用且保证永不签发的测试保留段。

当前身份法 `26/2023/QH15` 第 12 条规定个人身份编号为 12 位，由人口数据库建立、公安部统一管理。官方入口和日期在 JSON 的 `legalStatus.current12DigitBasis` 中。此项与历史公开结构应分别记录，避免把“当前法仍为12位”误写成“全部2026发号分配规则已确认”。

公安部 2026-05-12 对 `58/2026/NĐ-CP` 的说明确认，部分因性别、出生年或出生登记地资料更正而注销重建号码的条款已取消。因此，解析出来的编码历史信息不能用来否定某人的当前法定资料，不能称为身份事实核验。

## 已公开的结构与检查边界

12 个 ASCII 数字：3 位出生登记地区/国家编码 + 1 位世纪及编码性别 + 2 位出生年末两位 + 6 位随机段。国内 63 码完整列表在 JSON 中；国外出生国家码不在本次“越南全境”数据范围内。

世纪及编码性别公开表：1900–1999 为男 0 / 女 1；2000–2099 为 2 / 3；2100–2199 为 4 / 5；2200–2299 为 6 / 7；2300–2399 为 8 / 9。普通测试默认应限制到当前年份；未来年份仅作为明确选择的边界场景。号码没有出生月、日字段。

所核公开结构未规定独立校验位。可检查 12 位字符、选定版本的地区码存在性、世纪/性别编码、请求出生年一致性及批内重复；不得添加虚构校验算法或把“未设置校验位”显示为“校验通过”。尾六位的 `000000–999999` 是格式空间，不是经核实的实际签发区间；不存在排除真实身份的保证。

## 数据冲突及处理

政府 2023-01-12 教学页将 Bắc Giang 写成 023；文化体育旅游部 2022-08-25 官方完整表写 24，补足固定三位为 024；河静公安官方页面的搜索索引也写 024，但该站附件抓取因过期 TLS 证书失败，失败已保留在下载清单，不用于伪称本地原文已保存。机器数据采用文化部表中的 024，并保存冲突说明；未臆造 023。

63 码直接由保存的文化部 HTML 六列表格提取，全部按字符串补足三位；未从不连续的 001–096 范围枚举。34 个当前行政码逐项转录官方附录；归属映射逐项核对合并决议。Huế 的旧名是 Thừa Thiên Huế。
