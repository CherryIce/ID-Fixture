# ID Fixture 证号实验室

当前版本 **1.1.0+2**（2026-11-05）。Flutter本地测试数据应用，按国家、区域、证件和必要参数生成合成测试用例，展示支持的检查，导出JSON并按锁定版本复现。无账号、后台、默认遥测或真实身份核验。完整范围、产物和验证边界见[当前覆盖与交付记录](../docs/coverage/DELIVERY.md)。

## 当前规则范围

- 中国大陆：GB 11643结构与校验，提供31省级分组下的 **2851个公开参考候选代码**，支持原文地名/代码搜索及分层选择。此集合不是全国实际签发代码全集；特殊市级参考码与公开报道前缀保留各自限制，实际签发未知。
- 中国香港：公开格式及校验规则，可选1或2个大写字母前缀；规范输出不带括号，不推断出生日期、性别或签发地区。
- 中国澳门：公开格式层；**校验字符算法未知**，不提供校验位反例，也不把未知项标为通过。
- 中国台湾：22个当前地区前缀，另有4个须显式选择的历史前缀；支持编码性别与公开校验规则，历史前缀保持明确标记。
- 越南：启用公开历史结构测试；先以 **34个当前省级单位导航**，再选对应的 **63个公开历史出生地前缀**。当前两位行政码不是证件三位前缀。只编码出生年份，现行新签发分配符合性未知，不把历史解释当成当前身份事实。
- 美国：仍仅纽约州DMV ID与新一代护照本公开格式，NY须先选择州；不推广为全美驾照或完整签发算法。

旧版`cn-id-demo`保留为归档规则，仅供已有1.0用例包恢复与复现，仍是2022年北京3区演示，不静默升级到新档案。所有合成值可能与真实号码重合；格式或校验通过不证明实际签发、持有人或有效性。

## 开发与验证

Flutter 3.35.7 / Dart 3.9.2，FVM版本见.fvmrc。支持目标为iOS 13+、Android API 24+。锁定当前兼容插件版本，不修改全局工具链。

```sh
flutter pub get
flutter test test
# Android arm64 AOT 本地验收包（既有Debug证书；不配置生产签名）
./tool/build_android_local.sh
# iOS模拟器完整ad-hoc签名；参数替换为你选择的模拟器UDID
./tool/build_ios_simulator.sh 'id=<模拟器UDID>'
```

本轮 **53项Flutter测试、28项Node测试、6项Android集成业务测试**通过。Android集成使用真实偏好存储、平台服务和系统剪贴板；控制台的+8包含准备与收尾，不是8项业务测试。运行方法和完整证据见[本轮Android集成记录](../docs/coverage/validation/android-integration/README.md)。

Android普通1.1 AOT包首启921ms，仅为一次启动smoke，不是重复采样性能结论；系统分享和文件选择器本轮未重测。iOS本轮完成模拟器构建、签名、安装和启动截图，新地区菜单未通过CUA手动交互验证。1.0启动修订及原生分享/文件回读证据单独保留在[历史交付记录](../docs/mobile/DELIVERY-STARTUP-20261104.md)，不能替代本轮验收。均不延伸为真机、正式签名或商店验收。

首次引导可跳过/完成并持久化，设置可重看。默认语言和外观跟随系统，无法匹配的语言回退英文；仅显式偏好持久化，恢复跟随系统删除覆盖。存储不可用时仍可继续本次会话并显示警告。

号码结果不作历史保存。用户导出时创建独立临时文件，供系统分享扩展使用，由系统缓存管理；已保存/分享的外部副本由用户管理，应用不能撤回。文件导入按流限制1MB，严格校验结构、规则/引擎版本和数据哈希；不执行文件内容、不下载规则。

原创图标源与可重复生成脚本在branding/和tool/generate_brand_assets.py。iOS/Android配置原生启动页；iOS模拟器包采用完整ad-hoc签名，不能安装到真机。交付包在父目录outputs/，本轮产物名称、哈希与适用范围以[当前交付记录](../docs/coverage/DELIVERY.md)为准。正式签名/发行标识尚未配置，未上传或提交商店。

test/native_share_receiver/是独立本地QA分享接收夹具，不进入产品依赖或主APK；本轮没有用它重测系统分享与文件选择。
